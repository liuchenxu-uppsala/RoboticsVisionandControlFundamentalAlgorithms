## 3.1 Time-Varying Pose(位姿随时间的变化)

### 3.1.1 旋转矩阵的导数
- 从旋转矩阵正交性 R^T R = I 出发求导,证明 R^T·Ṙ 必然是反对称矩阵
- 两个版本,对应不同的"角速度测量视角":
  - **B系视角**(物体自身,如装在身上的陀螺仪):`Ṙ = R · [ω_B]×` ，此时 `R^T Ṙ = [ω_B]×`
  - **A系视角**(外部世界观察者):`Ṙ = [ω_A]× · R` ，此时 `Ṙ R^T = [ω_A]×`
  - 两者数值一般不同（除非只绕单一固定轴转这种特例），已用代码验证过
- 点符号 Ṙ、q̇、q̈：对时间求一阶/二阶导数（牛顿记号法），Ṙ 表示"此刻姿态变化的快慢"

### 3.1.2 Rate of Change of Pose(位姿的导数 → 空间速度)
- 对完整4×4齐次矩阵 T 求导，拆解出：
  - 线速度 v = ṫ（原点移动多快）
  - 角速度 ω（姿态转动多快，3.1.1的结果）
- 合并成6维**空间速度**(spatial velocity)：ν = (v, ω) ∈ R⁶ —— 这正是Jacobian公式 v=J(q)q̇ 里那个6维末端速度向量的正式定义来源
- ⚠️ 顺序约定：本书统一用 ν=(v,ω)，其他资料可能是(ω,v)，需注意

### 3.1.3 Transforming Spatial Velocities(坐标系间速度转换)
两种不同物理场景，对应不同工具：
- **场景一**：两个坐标系都固定，观察第三方物体运动 → 用速度转换Jacobian（只依赖旋转，与平移无关）
  ```python
  aJb = aTb.jacob()   # 6x6矩阵
  aV = aJb @ bV
  ```
- **场景二**：两坐标系刚性固连、一起运动（如base和末端，通过机械臂刚性连接）→ 用**伴随矩阵(Adjoint)**（依赖平移）
  ```python
  aV = aTb.Ad() @ bV
  ```

### 3.1.4 Incremental Rotation(增量旋转)—— 数值近似的理论基础
- 精确公式（矩阵指数，计算贵）：`R⟨t+δt⟩ = R⟨t⟩ · e^(δt[ω]×)`
- 一阶近似（计算便宜）：`R⟨t+δt⟩ ≈ R⟨t⟩ · (I + δt[ω]×)`
  - 推导：从 Ṙ=R[ω]× 出发，用导数定义 Ṙ≈(R(t+δt)-R(t))/δt，代数变形（移项+提取公因子R）得到
  - R必须乘在前面（不能只写 R+δt[ω]×）：因为角速度描述的转动是相对物体**当前已有姿态**而言的，必须把当前姿态R乘进去
- 用途：惯性导航/姿态估计——只知道瞬时角速度（如陀螺仪），通过反复小步累加，一步步推算出经过一段时间后的姿态
- 代价：反复"加法"更新会让矩阵逐渐失去正交性（不再是合法旋转矩阵），需要用 `trnorm()` 定期归一化修正
- 四元数也有对应的一阶近似（比旋转矩阵更便宜）

### 3.1.5 Incremental Rigid-Body Motion(增量刚体运动)—— IK误差的精确算法
- 两个位姿 ξ1,ξ2 差异很小，相对变换 `T = T1⁻¹T2 = [[R,t],[0,1]]`
  - t（3个数）= 位置差
  - R ≈ I + 反对称矩阵（由3.1.4的近似），用vex提取出3个数 r
- 6维误差向量：**δ = (t, r) ∈ R⁶**
- 这正是IK数值迭代(ikine_LM)内部，每一步计算"当前姿态vs目标姿态"误差、驱动收敛所用的误差表示
- 代价函数 e=‖δ(ξ1,ξ2)‖，ξ1=ξ2时等于0，用于优化/最小化过程
```python
delta = tr2delta(T1, T2)   # 两个位姿 → 6维误差
T2_approx = delta2tr(delta)   # 6维误差 → 近似还原位姿(用于验证/调试)
```
- 同样是近似，只在位姿差异很小时准确

## 3.2 Accelerating Bodies and Reference Frames(简要了解，不深入)
- 牛顿第二定律：`m·ẍ = f`
- 欧拉运动方程（角加速度与力矩）：`J·ω̇ + ω×(Jω) = τ`，J是惯性张量（转动惯量的3D推广）
- 没有力矩时，角速度不一定恒定（如太空翻滚卫星）；真正恒定的是角动量 h=Jω
- Wrench(力旋量)：力+力矩合并成6维向量 w=(fx,fy,fz,mx,my,mz)，是spatial velocity的"对偶"概念，同样用Adjoint矩阵在坐标系间转换
- （proposal范围内不涉及力矩控制，此节了解概念即可）

## 3.3 Creating Time-Varying Pose(生成随时间变化的轨迹)—— 对应第7章用过的jtraj/ctraj/mstraj的理论基础

### 3.3.1 Smooth One-Dimensional Trajectories(单轴平滑轨迹)
**为什么是五次多项式(quintic)**：起点终点各3个边界条件(位置/速度/加速度)=6个条件，需要6个系数，对应5次多项式
```python
traj = quintic(0, 1, np.linspace(0,1,50))
traj.q, traj.qd, traj.qdd   # 默认起点终点速度加速度都为0(平滑启停)
```
- 坑1：非零初始速度会导致超调（轨迹冲过目标值再折返）
- 坑2：quintic速度利用率不高（平均/峰值 约52%），因为速度曲线是钟形，中间才达到峰值

**梯形插值(trapezoidal)**：速度曲线分三段（加速抛物线→匀速直线→减速抛物线），速度利用率更高，工业常用
```python
traj = trapezoidal(0, 1, np.linspace(0,1,50), V=1.2)   # V可选，指定匀速段速度
```

### 3.3.2 Multi-Axis Trajectories(多轴轨迹)
- 把单轴插值推广到向量：每个轴各自独立、同步地做同样插值
- 配置向量q是通用记号：可以是关节角度、移动机器人位置、RPY姿态角、完整SE(3)位姿等
```python
traj = mtraj(trapezoidal, [0,2], [1,-1], 50)   # 参数1:用哪种单轴方法; 参数2/3:起点/终点向量; 参数4:步数
traj.q.shape   # (50, 轴数)
```
- ⚠️ 重要结论(已验证)：如果所有轴用**同一个**插值方法/同步时间，把两个轴的值直接当xy坐标画出来，路径**精确是直线**（因为共用同一个归一化形状函数s(t)，axis2是axis1的线性函数）
- 与"关节空间FK后末端路径是曲线"不矛盾：那是"直线在关节空间"经过**非线性**FK映射后，变成了物理空间里的曲线，是两个不同空间的概念，不要混淆

### 3.3.3 Multi-Segment Trajectories(多段轨迹，对应mstraj)
- 需求：连续平滑经过多个途经点(waypoints)，不完全停顿（如焊接、写字）
- **核心矛盾**：既要速度连续又要精确碰到每个中间点，数学上不可兼得 —— 必须放弃"精确经过"中间点
- 方法：直线匀速段 + quintic过渡段（"抄近路"绕过每个中间点，不真正停在那）
- tacc参数：转弯过渡总时长（接近途经点前tacc/2开始转，之后tacc/2转完）。tacc越大越平滑但离途经点越远，越小越贴近途经点但转弯越急促
```python
traj = mstraj(via, qdmax=[0.5,0.5,0.5], q0=via[0], dt=0.02, tacc=0.2)
traj.q   # (N,3) 实际轨迹点，会在每个via point附近"抄近路"，不精确经过
```

### 3.3.4 Interpolation of Orientation in 3D(3D姿态插值)
- **方法一：RPY/欧拉角线性插值** —— 简单但有两个问题：
  1. 转轴在插值过程中一直变化，看起来"不协调"
  2. 如果起点或终点靠近万向节死锁点，插值会出问题
- **方法二：四元数插值(SLERP, Spherical Linear Interpolation)** —— 更好
  - 沿4维超球面的"大圆"路径插值，对应3D里"绕一根固定轴匀速旋转"，运动更自然协调
  ```python
  q0 = UnitQuaternion(R0); q1 = UnitQuaternion(R1)
  qtraj = q0.interp(q1, 50)
  ```
- ⚠️ **不能对旋转矩阵直接做线性插值**：标量乘法+加法不是SO(3)群的合法运算，结果不再是合法旋转矩阵
- **方向选择**：两点间走"近路"还是"远路"（类似圆上两点，顺时针/逆时针距离可能不同）
  ```python
  q = q0.interp(q1, 50, shortest=True)   # 强制走最短路径
  ```

## 全程反复验证/推导过的核心要点(不要忘)

1. **Ṙ = R·[ω]×** 是精确公式，不是随意写的——从 R^T·Ṙ=[ω]× 两边左乘R得到，物理意义：角速度描述的转动是相对物体**当前姿态**而言的
2. **判断"绕哪个轴转，谁转向谁"永远用叉乘公式验证，不要靠脑补手势/站位**：
   - 绕X → Y→Z；绕Y → Z→X；绕Z → X→Y （循环规律 X→Y→Z→X）
   - 参考图见 [chapter2_review.md](../chapter2_pose/chapter2_review.md) 里的旋转方向参考图
3. **区分"配置空间里的直线"和"物理/笛卡尔空间里的路径"**：关节角度线性插值＝配置空间直线，但经过非线性FK后，末端在物理空间的路径通常是曲线；要末端物理空间走直线，必须用ctraj（在位姿空间直接插值，见第7章）
4. **6维向量的两种"表兄弟"**：spatial velocity ν=(v,ω)（描述运动）和 wrench w=(f,m)（描述力），概念上对偶，都用Jacobian/Adjoint在坐标系间转换

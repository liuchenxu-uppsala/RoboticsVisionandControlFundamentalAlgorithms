# 第4章复习:Mobile Robot Vehicles

(本章聚焦 4.1 Wheeled Mobile Robots,飞行/水下/高级主题部分未深入学习)

---

## 通用背景

- 移动机器人不只是地面轮式车辆,还包括无人机(UAV)、水下(AUV)、水面(ASV/USV)，统称自主无人系统(AUS)
- 配置向量统一记号：q=(x,y,θ) ∈ C，C⊆R²×S¹（位置x,y + 朝向角θ，通常只在2D地面平面讨论，不涉及Z轴）
- 坐标系{B}：原点随车身移动，X轴永远指向车辆前进方向；θ是{B}的X轴相对世界坐标系X轴转过的角度（车身朝向/heading）

---

## 4.1.1 Car-Like Vehicle(汽车型，自行车模型/Bicycle Model)

### 建模简化
- 把四轮车简化成"自行车"：后轮固定不转向(方向=车身方向)，前轮能转向(转向角γ)
- {B}坐标系原点 = 后轴中心（连接左右后轮那根轴的中点）；X轴沿车身方向(=后轮朝向)

### 瞬时转动中心(ICR, Instantaneous Center of Rotation)
- 假设：轮子只能沿自身朝向滚动，不能侧滑
- 每个轮子的"约束线"(垂直于该轮子朝向的线)延长后，必交于同一点 = ICR
- 车辆此刻正绕这一点做圆周运动（可类比"整块钢板固定在转盘上"：同一角速度，但板上不同点因半径不同而线速度不同）

### 关键三角形关系(后轮A为直角顶点，前轮B，ICR为C)
- 后轮到ICR：R_B = L / tanγ  （L=轴距=后轮到前轮的距离）
- 前轮到ICR：R_F = L / sinγ  （R_F > R_B，前轮离ICR更远，需要转得比后轮快，这是真实汽车需要差速器的原因）

### 运动学方程
```
ẋ = v·cosθ
ẏ = v·sinθ
θ̇ = (v/L)·tanγ        (推导：θ̇=v/R_B，代入R_B=L/tanγ)
```
- v: 后轮速度(可控)；γ: 前轮转向角(可控，方向盘)
- 正γ → 正θ̇ → 逆时针转动，圆心在运动方向的左手边（负γ则相反，圆心在右手边）—— 转动方向不能靠直觉猜，需代入公式/代码验证
- 这是**运动学模型**，只描述速度关系，不涉及产生这个运动需要多大力/力矩(区别于动力学模型)
- 真实四轮车转弯时左右前轮转向角应略有不同(Ackermann转向机构)，因为两者到ICR距离不同

## 4.1.2 Differentially-Steered Vehicle(差速驱动，独轮车模型/Unicycle Model)

### 结构特点：没有转向机构，靠左右轮速度差转向
- 典型结构：左右各一个驱动轮(并排，同一条垂直于前进方向的线上，无"前后"之分) + 前/后脚轮(castor，仅支撑，不驱动不转向)
- 大型的每侧用一对轮子共享一个电机；超大型(推土机/坦克)用履带

### Unicycle模型简化
- 把左右两个真实驱动轮，等效成一个"虚拟单轮"，位置在左右两轮连线的正中点
- {B}坐标系原点 = 这个中点；X轴沿车辆前进方向

### 运动学方程推导
- 左轮速度v_L沿半径R_L的弧运动，右轮速度v_R沿半径R_R的弧运动，θ̇=v_L/R_L=v_R/R_R（刚体角速度处处相同）
- 几何关系：R_R = R_L + W （W=轮距，左右轮间距）
- 推出：θ̇ = (v_R - v_L) / W

```
ẋ = v·cosθ
ẏ = v·sinθ
θ̇ = Δv / W
```
其中 v=(v_R+v_L)/2（平均速度），Δv=v_R-v_L（差速）

反过来，已知期望的v和θ̇，求左右轮速度(实际控制时用)：
```
v_R = v + (W/2)·θ̇
v_L = v - (W/2)·θ̇
```

### 与汽车模型的关键区别
- 转向速率θ̇与v无关（v=0时仍可转向）—— **可以原地转向**，这是汽车模型做不到的
- 但注意：能原地转向 ≠ 完整(holonomic)。原地转向本质是半径为0的极限圆周运动(ICR落在车身中心)，车辆朝向θ改变了，但依然不能不改变朝向就直接平移到任意方向
- 4轮差速车的轮轴并不真正指向ICR，转弯时轮子实际速度方向和路径切线方向有偏差，存在侧向分量违反"不打滑"假设 → 打滑/刮擦，原地转向时最严重，故差速转向也叫"滑动转向(skid steering)"
- 非完整约束(nonholonomic constraint)：`ẏcosθ - ẋsinθ = 0`

## 4.1.3 Omnidirectional Vehicle(全向轮车辆)

### 要解决的问题
汽车、差速驱动车都受"非完整约束"：不能在不改变朝向θ的前提下，直接向任意方向(如侧向)平移，必须先转向再前进，狭窄空间中机动性受限

### Mecanum轮(麦克纳姆轮/瑞典轮)
- 轮子周围装一圈"桶形"滚轮，滚轮轴线与轮子轴线成夹角α；桶形使任意时刻只有一点接触地面
- 轮子转动本身贡献沿轮子朝向(x̂_W)的速度分量(R·φ̇，R=轮半径)；接触点上的滚轮还能自由滚动，贡献一个不受控制的侧向速度分量
- 核心思路：把多个滚轮方向不同的Mecanum轮组合装在同一车上，通过分别控制各轮转速，叠加合成出任意方向的整体移动(不需要先转身)

### 差速驱动 vs 全向轮的核心区别(重要，容易混淆)
- **差速驱动"原地转"**：车辆朝向θ会改变(转90度后车头方向变了)，本质是半径为0的圆周运动
- **全向轮"平移"**：车辆朝向θ全程不变，只是位置整体挪动
- 这个区别在"车身上有方向性传感器/机械臂需要保持特定朝向"、或"车身非正圆形、狭窄空间连转身都困难"这两种场景下会造成实际差异
- "能不能横着走"是判断全向性的直观标准，更准确的定义是"能否不改变朝向、直接向任意方向移动"

## 全程反复验证/推导过的核心要点

1. **判断转动方向不能靠直觉，要代入公式/代码验证**：正γ(或正Δv)对应逆时针还是顺时针，取决于具体的公式符号约定，逆时针时圆心在运动方向左手边，顺时针时在右手边
2. **刚体上不同点，角速度相同、线速度因半径不同而不同**（可类比"钢板固定在转盘上"）——这条规律同时解释了R_B≠R_F、以及左右轮v_L≠v_R
3. **区分"能原地转"和"完整(holonomic)"**：前者只是朝向能变，后者是不改变朝向也能任意方向移动 —— 只有全向轮/Mecanum轮才是后者
4. 坐标系{B}原点选择因车辆结构而异：汽车→后轴中心；差速驱动→左右轮连线中点 —— 共同原则都是"放在驱动轮的中心"
